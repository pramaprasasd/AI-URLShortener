# Limitations

This repository is an interview assessment prototype.

Known limitations:
- `EnsureCreated` is used to make the Docker demo frictionless.
- Full SQL Server integration tests are not included in the fast CI suite.
- No user authentication.
- No admin API.
- No bot detection.
- No distributed cache.
- No asynchronous event broker for analytics.
- No geographic enrichment.
- No formal load-test result is claimed.
- Development SQL credentials are supplied only for local Docker execution.

These limitations are deliberate and documented rather than hidden.
